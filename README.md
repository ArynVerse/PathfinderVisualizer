# 🚀 Pathfinding Visualizer

An interactive Pathfinding Visualizer built using **React**, **TypeScript**, and **Vite** to demonstrate graph traversal algorithms through real-time animations.

## ✨ Features

- Interactive Grid
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Random Wall Generation
- Adjustable Animation Speed
- Clear Path
- Clear Board
- Responsive UI

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- HTML
- CSS

---

## 🧠 Algorithms Implemented

- Breadth-First Search (BFS)
- Depth-First Search (DFS)

## 💻 Installation

```bash
git clone https://github.com/ArynVerse/PathfinderVisualizer.git

cd PathfinderVisualizer

npm install

npm run dev
```
